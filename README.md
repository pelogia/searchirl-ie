# searchirl.ie

SearchIRL website. Built with [Astro](https://astro.build), content in Markdown, edited via [Keystatic](https://keystatic.com), hosted on [Netlify](https://netlify.com) and deployed from [GitHub](https://github.com/pelogia/searchirl-ie).

## Development

```bash
npm install
npm run dev
```

## Deploy

Push to `main` → Netlify auto-redeploys.
